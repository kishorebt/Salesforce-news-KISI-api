# Brand assets

`kisi-logo.png` — the exact, original KISI Salesforce Intelligence logo
(source file: `KISI Salesforce Intelligence Logo(20261010-092411).png`).
The pipeline pastes these bytes unchanged (proportional scaling only) onto every
post. It never draws or approximates the logo. If the file is missing, scheduled
publishing stops with `LOGO_MISSING` rather than posting off-brand.
